# CatSQL - A toy SQL Command line

CatSQL is a terrible SQL Command line made for, idk, schools? 

## Why did i make it? 

Well, MySQL is somewhat terrible nowadays so i thought why not make my own? 
Also, SQLite Syntax is somewhat complicated. Because i am choosing IT Next time,
i Should use this as my practising ground for SQL Instead of MySQL. 

Of course, other schools are welcome to use CatSQL (And possibly just name it
`MySQL`, tho it would break both this software license and MySQL EULA lol)
